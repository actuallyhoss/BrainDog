The owner's legal texts, one Markdown file each (`terms.md`, `privacy.md`, `processing.md`, `acceptable-use.md`, `refunds.md`), each opening "DRAFT for review, not in force" until he approves it. `/legal/<name>` draws `terms`, `privacy` and `processing` from here once `LAUNCH.legal` is on (`src/lib/launch.ts`), in plain Markdown: `##` and `###` headings, paragraphs and bullet lists. The folder is outside `src` so a company's name never meets the `shell-words` gate.
