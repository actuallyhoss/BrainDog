# The Mac app

A BrainDog window for the Mac is built and is held until its launch. It is the web app in its own window with the few things a browser tab cannot do: Option+Space from anywhere opens Slash, the Dock badge shows how many things need you, notifications arrive as the Mac's own, and it can open at login and hide when closed. Sign in with Google works in the window too, and it updates itself.

Until it launches there is no download page. Everything it does is in the browser at brain.dog now.
