# THAT DEFAULT BLOCKED CLAUDEBOT, GPTBOT, GOOGLE-EXTENDED, APPLEBOT-EXTENDED, CCBOT,
# META-EXTERNALAGENT, AMAZONBOT AND BYTESPIDER, and nobody here chose it: it is what the dashboard
# switches on for a new zone. This product's entire argument is that your agents can read and write
# your record, and its marketing site was telling the agents somebody would ask about it not to
# read it. A person asking Claude "what is BrainDog" got nothing, from the one page written to
# answer that question.
#
# THE PAGES ARE OPEN, THE APP IS NOT. The site is prose with no account and no data, so every
# crawler may read it. The record app is moving onto this origin: the Worker is to answer
# `brain.dog/app/`, `/api/`, `/auth/` and `/account/`, which are an app shell, JSON and sign-in
# behind authentication, and nothing a search result should point at. Until that route is live those
# four are this site's 404, so the rule costs nothing now and is already in place the day they
# start answering. The app is absent from the sitemap for the same reason.
