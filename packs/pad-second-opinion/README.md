# Pad second opinion

A second opinion written under each note on the pad: two or three plain sentences on what the note gets right and
what it may be missing.

- **It needs the pad.** The pad is the notes and their page, and asks no model, so anyone can keep one. This plugin
  brings the one thing the pad left out: an automation on the notes that asks Slash about a note with no reply and
  writes the answer back as its reply.
- **It asks your record's model, and spends its allowance.** Every note written with no reply is one question.
  Write a reply yourself and nothing is asked. A host with no model refuses it at install, and the pad stays.
- **Asking again is rewording the note.** Clearing a reply on the same words asks nothing, so a note is never put to
  the model twice for the same thing.
- **Taking it out keeps every reply.** The automation goes and the notes stay, with what was written under them.

It is the rule pad 1.1.0 held, word for word and under the same name. A pad kept from 1.1.0 that takes 1.2.0 and
then this plugin is not asked again about a note it already answered.
