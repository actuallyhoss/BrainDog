# Team task list

For a small team, or one person with agents, that wants a plain shared task list. Each task has an owner, and an owner is either a person or an agent.

- **Team** lists the people and agents who can own a task.
- **Board** moves tasks across To do, Doing, In review, Blocked and Done, urgent ones first.
- **Who is doing what** shows the agents working right now, read from their sessions, and the tasks each person holds in progress.
- Nothing runs by itself. One automation is written and switched off: it asks who can unblock a task when it is marked blocked.
- The preview is made of invented examples. Needs nothing else installed.
