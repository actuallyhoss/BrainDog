# Starting a project

For someone with a new idea who wants a guide: a side project, a small business, a book, a club. It walks one project through three stages, from idea to first users to first money.

- **Next steps at each stage** are a checklist. You or an agent can tick a step, and an agent's name is kept beside it.
- **Decisions with reasons.** Write what you chose and why, so you can read it back in a month.
- **A weekly page**, "This week": where it stands, what comes next, what is in the way, and what was ticked in the last seven days.
- Nothing runs by itself. One automation is written and switched off: it asks about moving on when a step is ticked.
- The preview is made of invented examples. Needs nothing else installed.
