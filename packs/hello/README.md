# Hello
A list of things to do and a page showing what is still open: the smallest useful plugin.
Edit hello.pack.json, then run braindog pack check hello to see what a record would say about it.
Run braindog pack test hello to write the rows in hello.test.json into a scratch BrainDog and check what it expects.
Publish it with braindog pack publish hello.pack.json --kennel, signed with --sign <key file> or as the person signed in.
