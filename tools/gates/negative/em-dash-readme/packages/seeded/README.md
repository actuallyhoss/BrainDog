# seeded-published

A published package's README is the page somebody reads before they have the repository, so the
rule reaches it. Every line above the last one is a decoy.

```
{{money:129900 EGP}}    EGP 1,299.00    — minor units, code first
{{date:2026-09-26}}     26 Sep 2026     — links to the calendar
```

A fenced block draws what a document turns into, and the column that separates the source from the
result is a dash spaced on both sides. That is a drawing and not a sentence.

A missing value renders as `an em dash — never blank`, quoted here as code rather than said.

<!-- An HTML comment in markdown is not prose either, for the same reason it is not prose in a
     .ts file: the person this rule is about never sees it. -->

A seeded sentence — in prose, outside any fence.
