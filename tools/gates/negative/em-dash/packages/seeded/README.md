# seeded-published

A published package's README is read by somebody who has not cloned this repository, so the rule
reaches it. Every line below is a decoy: none of them is prose.

```
{{money:129900 EGP}}    EGP 1,299.00    — minor units, code first
{{date:2026-09-26}}     26 Sep 2026     — links to the calendar
```

A missing value renders as `an em dash — never blank`, quoted here as code rather than said.
